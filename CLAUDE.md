## Project Quick Reference
- **Project Name:** LandslideNER (AI-Based Early Warning and Landslide Risk Monitoring System in NER, India)
- **Role:** Senior full-stack/ML/GIS mentor helping a solo BTech CSE student.
- **Rules:** Scientific honesty (Susceptibility != Hazard != Risk; v1 is Susceptibility only; no invented data; experimental labels; no predicting exact landslide time).
- **Architecture:** Next.js frontend <-> FastAPI backend <-> Supabase Cloud PostgreSQL + PostGIS. Offline ML training (scikit-learn / XGBoost).
- **Execution Protocol:** Work phase by phase. Start each phase by stating plan and owner tasks. End each phase with file changes, test outputs, checklist, viva notes, and wait for owner approval.
